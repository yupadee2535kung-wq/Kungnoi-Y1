# 📁 โฟลเดอร์ Public (Kungnoi Y. - Debut Album Website)

โฟลเดอร์นี้ใช้สำหรับวางไฟล์เพลง MP3 และไฟล์รูปภาพจริง เพื่อให้โปรเจกต์สามารถเปิดฟังและแสดงผลบน Vercel, Netlify, GitHub Pages หรือโฮสติ้งจริงได้ทันที

---

### 🎵 1. วิธีวางไฟล์เพลง MP3 (`/public/audio/`):
วางไฟล์เพลง MP3 ทั้ง 10 บทเพลงของคุณลงในโฟลเดอร์ `public/audio/` โดยตั้งชื่อไฟล์ตามหมายเลขแทร็กดังนี้:
- `01.mp3` : เพลง ถ้าเธอยังไม่ลืม
- `02.mp3` : เพลง อย่ามองแบบนั้น
- `03.mp3` : เพลง กลิ่นกาแฟในวันฝนตก
- `04.mp3` : เพลง ข้อความที่ลบไป
- `05.mp3` : เพลง ก่อนที่เธอจะปล่อยมือ
- `06.mp3` : เพลง รถไฟขบวนสุดท้าย
- `07.mp3` : เพลง กอดตัวเองในวันที่ไม่มีเธอ
- `08.mp3` : เพลง เงาในกระจก
- `09.mp3` : เพลง อีกครั้ง...ถ้าเป็นไปได้
- `10.mp3` : เพลง Made for You, Only You

*(เมื่อวางไฟล์ครบแล้ว เว็บไซต์จะเล่นไฟล์เพลง MP3 จริงอัตโนมัติ 100%)*

---

### 🖼️ 2. วิธีวางไฟล์รูปภาพ (`/public/images/`):
วางรูปภาพลงในโฟลเดอร์ `public/images/`:
- `cover.jpg` : รูปหน้าปกอัลบั้มหลัก (สัดส่วน 1:1 จัตุรัส ขนาด 1000×1000 px)
- `hero_banner.jpg` : รูปภาพบรรยากาศเวที (สัดส่วน 16:9 หรือ 2.1:1 ขนาด 1920×900 px)
- `slide_01.jpg` ถึง `slide_05.jpg` : รูปสไลด์โชว์สำหรับหน้าแรก
